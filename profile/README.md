## 关于我们

**bioinfo-ccnu** 是一个正在建设的生物信息学科研协作空间。我们希望将分析代码、研究方法和学习经验整理成清晰、可复现、便于交流的项目，让研究过程更容易理解、验证和延续。

### 我们希望在这里积累

| 内容 | 项目目标 |
| --- | --- |
| 分析流程 | 记录输入、参数、软件环境与运行步骤，帮助他人复现分析 |
| 方法与工具 | 分享数据处理、统计分析和结果可视化的代码 |
| 学习资源 | 整理实践笔记、示例和常见问题，降低上手门槛 |
| 研究复现 | 将论文或研究问题与代码、数据来源和结果对应起来 |

### 从哪里开始

- **了解项目**：在[仓库列表](https://github.com/orgs/bioinfo-ccnu/repositories)中查找项目，先阅读对应 README 中的用途、环境与示例。
- **反馈问题**：优先在相关项目提交 Issue，附上最小示例、软件版本和预期结果。
- **参与贡献**：阅读[贡献指南](https://github.com/bioinfo-ccnu/.github/blob/main/CONTRIBUTING.md)，通过 Pull Request 提交代码、文档或示例。
- **发起项目**：参考[新项目指南](https://github.com/bioinfo-ccnu/.github/blob/main/docs/starting-a-project.md)，从可运行的小例子开始。

组织刚刚建立，研究项目将逐步加入。目前的公共仓库 [`.github`](https://github.com/bioinfo-ccnu/.github) 用于维护组织介绍与协作规范。欢迎通过 [Issue](https://github.com/bioinfo-ccnu/.github/issues/new/choose) 提出资源建议或交流合作想法。

## About

**bioinfo-ccnu** is a growing collaboration space for bioinformatics and reproducible research. We aim to share analysis workflows, methods, practical learning resources, and reproducible examples with clear documentation of data sources, software environments, and analytical steps.

Explore our [repositories](https://github.com/orgs/bioinfo-ccnu/repositories), read the [contribution guide](https://github.com/bioinfo-ccnu/.github/blob/main/CONTRIBUTING.md), or open an [issue](https://github.com/bioinfo-ccnu/.github/issues/new/choose) to suggest a resource or discuss collaboration. Chinese and English contributions are welcome.
