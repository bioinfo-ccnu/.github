# Support

| Need | Where to go |
| --- | --- |
| Installation, usage, or analysis results | The affected project's README and issue tracker |
| Bugs or feature requests | The affected project's issue tracker |
| Research questions and resource sharing | [Discussions](https://github.com/bioinfo-ccnu/.github/discussions) |
| Organization profile or shared templates | [Organization issues](https://github.com/bioinfo-ccnu/.github/issues/new/choose) |
| Collaboration enquiries | [Lei Wang's contact page](https://wangleiofficial.github.io/contact/) |
| Security vulnerabilities | Follow [SECURITY.md](SECURITY.md) |

For technical questions, include the project version, environment, command, and a minimal public or synthetic example. Search existing issues before posting. Maintenance arrangements and project-specific support details belong in each project's README.
